WEPLACE × MASHCORE | 청환 공유용 감각 체험 소개서 v2
작성: 2026-11-03

가장 쉬운 사용 방법
1. ZIP 파일을 내려받아 압축을 해제합니다.
2. index.html을 Chrome/Edge/Safari 브라우저로 엽니다.
3. 인터넷 연결 없이도 아래 기능이 작동합니다.
   - 정리 전/후 매장 화면 비교
   - 첫 사진 / 공간·조명 / 안내 문장 / 리듬 관찰 포인트
   - 예약 방법 버튼의 가상 시연
   - 고객 여정 5단계 선택
   - 방문 세션, 클릭률, 예약 확정, 실제 방문, 거래액 계산기
   - 핵심 내용 복사, 브라우저 PDF 인쇄

중요
- 화면의 매장 C와 예약 장면은 모두 가상 예시입니다. 실제 예약이 생성되지 않습니다.
- 계산기의 지표는 사용자가 정하는 가정이며 매출 예측, 성과 보장, 인과 입증이 아닙니다.
- 익명 실적 비교는 Weplace R2 검토자료의 기간별 관측값으로, 개별 작업 기여도가 분리되어 있지 않습니다.
- 사업 소개의 개발 상태는 2026-11-03 기준입니다. R2/R4, FLOW 최신 기능, CMS, CRM은 운영/검토/계획을 구분합니다.
- 청환의 StayMind와의 실제 연동·참여는 확정되지 않았습니다.
- 페이지는 외부 폰트·사진·JS 라이브러리·CDN을 불러오지 않습니다. 다만 하단의 홈페이지/FigJam 링크는 인터넷이 필요합니다.

온라인 공유가 필요하면 별도 비공개 미리보기 배포 후 링크를 전달하세요.
